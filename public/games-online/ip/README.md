# 🕸️ Ip

**Bitta arqon — otil, tebran, uch.** Momentumga asoslangan tebranish o'yini.
Yurmaysiz; faqat mayatnik tebranishi va inersiya bilan harakatlanasiz.

## Yangi (original) mexanika

Sizda **bitta arqon** bor. Uni yuqoridagi **langar** nuqtaga otasiz va
mayatnik fizikasi bilan **tebranasiz**. Kerakli lahzada qo'yib yuborsangiz,
to'p o'z tezligi (impulsi) bilan **uchib ketadi** — so'ng yangi langarni
tutasiz. Mahoratli vaqt tanlash uzoqroq masofa bilan mukofotlanadi (qo'yib
yuborilganda kichik impuls bonusi beriladi).

- Arqon **eng yaqin yetib boradigan** langarga otiladi (maksimal masofa ichida,
  taxminan tepada).
- Arqon ushlab turilganda qattiq masofa cheklovi to'pni doira bo'ylab tutadi —
  gravitatsiya tabiiy tebranishni hosil qiladi.
- Dunyo o'ngga siljiydi (kamera kuzatadi), langarlar prosessual generatsiya
  qilinadi. Pastga tushib ketsangiz — **o'yin tugaydi**.

## Boshqaruv

- **Space** (bosib turing) — arqon otiladi va tebranasiz; **qo'yib yuboring** —
  uchasiz.
- **Sichqoncha / barmoq** — bosib turing va qo'yib yuboring (mobil uchun
  `pointerdown` / `pointerup`, touch zaxirasi bilan).

## Ball

Masofa metrlarda hisoblanadi. Eng yaxshi natija brauzerda `localStorage`
(`ip-best`) da saqlanadi.

## Mustaqil deploy

Bu papka **mustaqil** — faqat shu papkani deploy qilsa bo'ladi
(Vercel / Netlify / GitHub Pages). Tashqi build, framework yoki tarmoq kerak
emas — sof HTML/CSS/JS, `index.html` ni brauzerda ochsangiz ishlaydi.

> Deploy sozlamasida **Root Directory = `games/ip`** qilib belgilang.
