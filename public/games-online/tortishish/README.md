# 🌍 Tortishish (Gravity)

Tortishish — bu boshqotirma o'yin bo'lib, unda siz sharni **to'g'ridan-to'g'ri
harakatlantirmaysiz**. Uning o'rniga siz **tortishish yo'nalishini** o'zgartirasiz,
shar esa o'sha tomonga dumalab tushadi — devor yoki to'siqqa urilguncha.

## Yangi mexanika

Odatiy o'yinlarda tugmalar qahramonni suradi. Bu yerda tugmalar **butun dunyoning
tortishishini buradi**. Yuqoriga bossangiz — shar yuqoriga "tushadi"; o'ngga
bossangiz — o'ngga sirg'aladi. Har bir yo'nalish sharni to'siqqacha uzatadi.
Vazifa — tortishishni to'g'ri ketma-ketlikda burib, sharni yashil chiqishga (G)
yetkazish va qizil tikonlardan (^) qochish.

## Qanday o'ynash

- **Strelkalar** yoki **WASD** — tortishish yo'nalishini o'rnatadi (yuqori, past,
  chap, o'ng).
- **R** — joriy darajani qaytadan boshlaydi.
- Mobil qurilmalarda ekrandagi **4 ta strelka tugmasi** ishlaydi.
- Shar tikonga tegsa — daraja qayta boshlanadi (qizil chaqnash).
- Shar chiqishga (G) yetsa — keyingi darajaga o'tasiz.

## Belgilar

- `#` — devor
- `.` yoki bo'sh joy — bo'sh katak
- `^` — tikon (o'lim)
- `G` — chiqish (maqsad)
- `S` — sharning boshlang'ich joyi

## Ochkolar

Har bir tortishish o'zgarishi (yurish) sanaladi. Kamroq yurish — yaxshiroq natija.
To'liq o'yin bo'yicha eng kam yurishlar `localStorage` da (`tortishish-best`
kaliti) saqlanadi.

## Texnik

- Sof statik HTML/CSS/JS — hech qanday build, framework yoki tarmoq so'rovi yo'q.
- `index.html` faylini brauzerda ochish kifoya.
- Mustaqil deploy qilinadi: **Root Directory = `games/tortishish`**.
