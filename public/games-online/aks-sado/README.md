# ⚡ Aks-sado (Oyna Ilon)

Ilon o'yinining fantaziya versiyasi. Ekran ikkiga bo'linadi:
- **Chap tomon** — siz boshqaradigan ilon
- **O'ng tomon** — uning **ko'zgu (mirror) aksi** (chap/o'ng teskari, yuqori/past bir xil)

Har ikkala ilonning **o'z ovqati** bor, shu sabab vaqt o'tib ular har xil
uzunlikda bo'ladi — bir xil harakat birini urib, ikkinchisini urmasligi mumkin.
**Ikkalasini ham tirik saqlash** — asosiy sinov (miya mashqi).

## O'ynash
- Faylni brauzerda oching: `index.html` (build kerak emas)
- Boshqaruv: `← ↑ → ↓` yoki `W A S D`
- Pauza: `Space`
- Mobil: ekrandagi tugmalar

## Deploy
Bu papka mustaqil — faqat shu papkani statik sayt sifatida deploy qiling
(masalan Vercel'da `Root Directory = games/aks-sado`).

## Fayllar
- `index.html` — sahifa va HUD
- `style.css` — dizayn
- `game.js` — o'yin mantig'i (Canvas, mirror mexanikasi)
